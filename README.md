# Market Pulse

Инструмент отбора криптовалютных фьючерсов для ручного анализа.

Из нескольких сотен инструментов на Binance и OKX отбирает те, которые
**ведут себя необычно относительно своего собственного обычного состояния**,
и объясняет, по каким признакам каждый из них попал в список.

> Это не торговый бот. Система не даёт сигналов на покупку и не предсказывает
> цену. Её задача — сократить список инструментов, которые стоит открыть
> и посмотреть глазами.

**Статус:** в разработке. Реализованные этапы отмечены ниже.

---

## Зачем

При ручном поиске точек интереса трейдер пролистывает сотни графиков подряд.
Большинство инструментов неликвидны или неактивны, и основное время уходит
не на анализ, а на поиск того, что вообще достойно анализа.

Market Pulse автоматизирует именно этот отсев.

---

## Как это работает

```
Список инструментов  →  Фильтры  →  Метрики  →  Скоринг  →  Отчёт
     ~400 шт            ~290 шт     RVOL       ранжирование   топ-15
                                    RTC                       + объяснение
                                    VE
```

Три метрики, каждая сравнивает последнюю закрытую свечу с обычным поведением
инструмента за предыдущие 48 часов (медиана, не среднее):

| Метрика | Что показывает |
|---|---|
| **RVOL** | во сколько раз объём выше обычного |
| **RTC** | во сколько раз больше сделок, чем обычно |
| **VE** | во сколько раз шире диапазон свечи |

Точные формулы, окна и пороги — в [docs/spec.md](docs/spec.md).

### Пример вывода

```
BINANCE   проверено 412 → после фильтров 287 → кандидатов 15

 1. SUI/USDT                    score 2.31
    Изменение за свечу:  +4.2 %

    Почему в списке:
    • Объём свечи 8.4M USDT — в 4.1× выше обычного
      (обычная свеча 15m за 48 ч: 2.0M USDT, медиана)
    • Сделок 31 400 — в 2.9× больше обычного
    • Диапазон свечи 3.8 % — в 2.4× шире обычного
```

Пользователь всегда видит и коэффициент, и абсолютные числа, из которых он
получен. Непрозрачный «score 2.31» без обоснования — сознательно исключён.

## Установка

```bash
git clone https://github.com/mapEL21/market-pulse.git
cd market-pulse

python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

Ключи API не нужны — используются только публичные эндпоинты бирж.

## Запуск

```bash
python -m src.main
```

## Исследовательская часть

Каждый прогон сохраняется в базу вместе с тем, что происходило с ценой
инструмента **после** попадания в список. Это превращает инструмент
в проверяемую гипотезу и позволяет отвечать SQL-запросами на вопросы:

- при каких значениях метрик чаще случались сильные движения;
- какие пороги дают больше всего ложных срабатываний;
- отличается ли поведение кандидатов на разных биржах.

Пороги и веса в скоринге — стартовая гипотеза, а не подобранные константы.
Их проверка на накопленных данных — отдельный этап проекта.
